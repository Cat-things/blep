## Welcome to Blep

Blep handles the stuff every server needs: moderation, antinuke, welcome messages,
reaction roles, tickets, VoiceMaster, levels, music, Last.fm and more. There are no tiers,
no paywalls and no "donator perks". Everything is free.

<Info>
  Blep answers to **two prefixes** by default: `,` and `;`. Both work everywhere,
  so `,help` and `;help` do the same thing. Use `,prefix set (symbol)` to swap them
  for your own.
</Info>

## Coming from bleed?

Blep's commands, flags and embed scripts follow the same conventions as bleed. Your existing
`{embed}$v{...}` scripts and variables work unchanged, so moving a server over mostly means
re-running your setup commands. See [Why Blep](/overview/why-blep) for the differences.

## Open source

Blep is open source. You can read the code, report bugs, suggest features or

## Free, forever

Blep has no premium tiers. Features other bots charge for are free here:

| Feature | bleed | Blep |
| ------- | ----- | ---- |
| Custom personal prefix (`prefix self`) | Tier 2 | Free |
| Last.fm custom embed (`lastfm mode`) | Tier 1 | Free |
| Last.fm custom reactions (`lastfm cr`) | Tier 1 | Free |
| VoiceMaster ghost (`voicemaster ghost`) | Tier 2 | Free |
| ChatGPT (`chatgpt`) | Tier 1 | Free when the host sets an API key |
| Video to GIF / background removal | Tier 2 | Not included yet |
| Vanity roles | Separate bot, slash only, level 3 servers | Built in, prefix commands, any server |

## Two prefixes by default

Blep listens to both `,` **and** `;` out of the box, so muscle memory from other bots just works.

## Compatible scripting

Blep reads the same embed script format (`{embed}$v{title: ...}`) and the same variables
(`{user.mention}`, `{guild.name}` ...), so you can paste your existing welcome messages,
autoresponders and level-up messages straight in.

## Little upgrades

- Flags accept iOS "smart dashes": `—do ban` works the same as `--do ban`.
- Embed scripts can hold several embeds: start each one with `{embed}`.
- `help` cards show the required permissions, syntax and a real example for every subcommand.
- Self-hostable: run your own copy with Docker in a couple of commands.

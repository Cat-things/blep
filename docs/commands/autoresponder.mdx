## autoresponder

| | |
| --- | --- |

| **Aliases** | `ar` |

### autoresponder add

Create an auto responder. Separate the trigger and response with a comma. Flags: --not_strict, --self_destruct (6-60), --delete, --reply, --ignore_command_check

| | |
| --- | --- |
| **Syntax** | `,autoresponder add (trigger, response) <flags>` |
| **Example** | `,autoresponder add welc, welcome to the server! --self_destruct 10 --reply` |
| **Aliases** | `create` |
| **Permissions** | `manage guild` |

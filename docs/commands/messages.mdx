## boost

Send a message whenever a member boosts the server

| | |
| --- | --- |
| **Syntax** | `,boost` |

### boost add

Add a boost message to a channel (one per channel). Supports embed scripts and variables

| | |
| --- | --- |
| **Syntax** | `,boost add (channel) (message) <--self_destruct 6-60>` |
| **Example** | `,boost add #general thank you for boosting {user.mention}, that's {boost.count} boosts from you --self_destruct 30` |
| **Aliases** | `create`, `set` |
| **Permissions** | `manage guild` |

### boost list

View every boost message in this server

| | |
| --- | --- |
| **Syntax** | `,boost list` |
| **Permissions** | `manage guild` |

| **Aliases** | `delete`, `del` |

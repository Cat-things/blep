## log

Log server events to channels

| | |
| --- | --- |
| **Syntax** | `,log` |
| **Aliases** | `logs` |

### log add

Log an event in a channel. Events: messages, members, roles, channels, invites, emojis, voice. Leave the event out to log everything

| | |
| --- | --- |
| **Syntax** | `,log add (channel) <event>` |
| **Example** | `,log add #logs messages` |
| **Aliases** | `set` |
| **Permissions** | `manage guild` |

| | |

| **Permissions** | `manage guild` |

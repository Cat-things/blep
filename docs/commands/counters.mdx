## counter

Create channels that show live server statistics or a countdown

| | |
| --- | --- |
| **Syntax** | `,counter` |
| **Aliases** | `counters` |

### counter add

Add a counter. Options: members, users_only, bots_only, pending_members, all_channels, text_channels, voice_channels, categories, announcement_channels, stage_channels, boosts, booster_count or a unix timestamp. Types: voice, text, category, announce, stage. Customise the name with `--name` and `{count}`

| | |
| --- | --- |
| **Syntax** | `,counter add (option) <type> <--name template>` |
| **Example** | `,counter add members voice --name {count} members` |
| **Aliases** | `create` |
| **Permissions** | `manage channels` |

### counter list

### counter remove

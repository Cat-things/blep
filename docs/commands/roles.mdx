## buttonrole

Let members assign themselves roles with buttons on Blep's messages

| | |
| --- | --- |
| **Syntax** | `,buttonrole` |
| **Aliases** | `btnrole` |

### buttonrole add

Add a role button to a message sent by Blep. Styles: green, blurple, gray, red

| | |
| --- | --- |
| **Syntax** | `,buttonrole add (message link) (role) (style) (emoji) (label)` |
| **Example** | `,buttonrole add https://discord.com/channels/1/2/3 @Verified green ✅ Verify` |
| **Aliases** | `create` |
| **Permissions** | `manage roles` |

title: Permissions
description: "Permission names used by Blep and fake permissions."
icon: shield
---

| Permission | Lets members... |
| ---------- | --------------- |
| `administrator` | Use every Blep command that needs a permission |
| `ban_members` | Ban, unban, softban and tempban |
| `kick_members` | Kick members |
| `moderate_members` | Timeout, mute, jail and warn |
| `manage_guild` | Change server settings and most configuration commands |
| `manage_channels` | Lock, hide, nuke and slowmode channels |
| `manage_roles` | Use the role commands |
| `manage_messages` | Purge, clear snipes and manage embeds |
| `manage_nicknames` | Change nicknames |
| `manage_webhooks` | Create and use webhooks |
| `manage_expressions` | Add, steal and remove emojis & stickers |
| `manage_threads` | Manage threads |
| `manage_events` | Manage scheduled events |
| `view_audit_log` | View the audit log |
| `mute_members` | Voice mute members |
| `deafen_members` | Voice deafen members |
| `move_members` | Drag and move members between voice channels |
| `mention_everyone` | Mention everyone |
| `view_guild_insights` | View server insights |
| `external_emojis` | Use external emojis |
| `change_nickname` | Change their own nickname |

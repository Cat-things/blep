Variables work in any command that stores a message or an embed script (`welcome`, `goodbye`,
`boost`, `autoresponder`, `levels message`, `invoke` ...). Unknown variables are left as they are.

## Functions

Wrap a variable in a function to transform it:

| Function | Output | Example |
| -------- | ------ | ------- |
| `lower(...)` | lowercase | `{lower(user.name)}` |
| `upper(...)` | UPPERCASE | `{upper(guild.name)}` |
| `title(...)` | Title Case | `{title(channel.name)}` |
| `proper(...)` | Number with commas | `{proper(guild.count)}` |
| `len(...)` | Length of the value | `{len(user.name)}` |

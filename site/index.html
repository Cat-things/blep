FAQ

Questions, answered

Is it actually free?

Yes. Every feature is free for every server, and there's no premium tier waiting to upsell you later. Blep is open source under Apache-2.0, so if we ever got weird about it you could just run your own copy.

Will my bleed embed scripts work?

That's the idea. Blep reads the same {embed}$v{...} format and variable names, so welcome, boost and autoresponder scripts can be pasted straight in.

Which prefix do I use?

Both , and ; work out of the box, so ,help and ;help do the same thing. Admins can swap the server prefix with ,prefix set, and anyone can add a personal prefix with ,prefix self. Also free, obviously.

What permissions does it need?

The invite asks for Administrator so antinuke and moderation can do their jobs. You can untick permissions on the invite screen, but some features will stop working without them.

Can I host it myself?

Yep. Grab the source from GitHub and follow the self-hosting guide. Docker Compose gets you running in a couple of commands.
